# ADR NNNN: Tytuł decyzji

- **Status:** Propozycja | Przyjęta | Zastąpiona przez ADR NNNN
- **Data:** RRRR-MM-DD

## Kontekst
Jaki problem rozwiązujemy i jakie są ograniczenia.

## Rozważane opcje
1. Opcja A — plusy / minusy
2. Opcja B — plusy / minusy

## Decyzja
Którą opcję wybieramy i dlaczego.

## Konsekwencje
Co z tego wynika (koszty, ograniczenia, dalsze kroki).
